# Final check

Run this after every edit or draft. Answer each item pass or fail. Fix every failure and run the list again before returning anything.

## Meaning

- [ ] The point, claims, numbers, examples, and opinions match the source (unless the user asked for substantive changes).
- [ ] Nothing was invented: no facts, sources, quotes, metrics, experiences, or extra certainty.
- [ ] Claims that need a source and lack one are flagged in **What changed**. They are not quietly kept or quietly deleted.

## Voice

- [ ] Distinctive vocabulary, cadence, humor, bluntness, hedges, and rough edges survived.
- [ ] Strong sentences were left alone rather than rewritten for consistency.
- [ ] The amount of editing matches the amount of slop. A clean draft got a light touch.
- [ ] If a voice profile was supplied, the output follows it (contractions, sentence length, banned or preferred words, sign-offs).
- [ ] The writer would recognize this as their own.

## Clarity

- [ ] The point arrives without generic warm-up.
- [ ] Abstract claims were replaced with facts, mechanisms, or examples that exist in the source.
- [ ] Every sentence passes the portability test or was tied to this subject.
- [ ] Plain verbs and active voice where they are clearer. One name per thing.
- [ ] Genre rules from contexts.md were applied.

## Patterns

- [ ] Framing (A): no secret-insight setups, tee-ups, staged candor, generic scene-setting, assistant residue, or (outside docs) definition openers.
- [ ] Structure (B): no binary reframes, negative stacks, fake Q&A, colon reveals, or fragment stacks. No forced triads, template paragraphs, false balance, empty ranges, or stuffed sentences.
- [ ] Rephrased variants checked at sentence and paragraph level. Swapping words did not leave the same staged move in place.
- [ ] Claims (C): no importance labels, hollow "-ing" analysis, reaction narration, vague authority, hedge stacks, unbacked sales promises, or straw competitors.
- [ ] Vocabulary (D): stock words, filler phrases, and empty adverbs removed unless precise or part of the voice. No synonym cycling.
- [ ] Endings (E): no kicker, recap, or engagement bait. The piece ends on a concrete point or next action.
- [ ] Formatting (F): no em dashes, en dashes, or semicolons. No sentence over 20 words. No unrequested emojis, decorative bold, or bullets and headings that should be prose.

## Rewrite strength (only when a rewrite was requested or warranted)

- [ ] The opening gives the reason or problem before the definition, if the source supports one.
- [ ] Claims about other tools or people became the writer's own motive, a named comparison, or were cut. No invented backstory.
- [ ] One idea per sentence. No appositive-plus-list-plus-"and" pile-ups.
- [ ] What the reader cares about (price, audience, benefit) comes before credits and implementation details.
- [ ] Every fact from the original is still there.
- [ ] Any platform tip is a note after the draft, not inside it.

## Output

- [ ] Read aloud, it sounds like a sharp person talking to a colleague.
- [ ] The response contains what was asked for and nothing else: no lecture, no preamble.
- [ ] Edit mode: full draft plus a short **What changed**. Audit mode: pattern, quote, and fix for each finding, no rewrite, no score, no authorship guess.
