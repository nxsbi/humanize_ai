# Changelog

## 1.2.0 (2026-11-12)

- Five before-and-after examples (LinkedIn, email, website, report, launch rewrite) in `references/examples.md`, linked from `SKILL.md` for calibration and shown in the README.

## 1.1.0 (2026-11-12)

- `humanize` now has two edit strengths. Light (default) fixes patterns only. Rewrite keeps every fact but changes delivery: opens with why instead of a definition, turns claims about competitors into the writer's own motive, splits stuffed sentences, uses spoken verbs, and moves what the reader cares about forward.
- New patterns: A6 definition openers, B10 stuffed sentences, C7 straw competitors.
- LinkedIn guidance for launch posts and links; README exception for definition openers.
- Checklist section for rewrites.

## 1.0.0 (2026-11-12)

- `humanize` skill: edit, audit, and draft modes; 30+ patterns in six groups (framing, structure, claims, vocabulary, endings, formatting); genre adjustments for email, social, docs, reports, resumes, web copy, academic writing, and chat; final checklist.
- `voice-profile` skill: builds a `voice-profile.md` from writing samples that `humanize` follows.
- `scan.py`: standard-library scanner that flags patterns with line numbers, JSON output, and a CI exit code.
- Claude Code plugin and marketplace manifests.
